fix(routes): 深链初始路由栈只压「首页 + 目标页」两层

去掉写死的 initialRoute 之后，深链确实能直接打开目标页了，但 Flutter 默认会
把 initialRoute 按 `/` 逐段拆分压栈：`/goods/list?...` 变成
`/` → `/goods` → `/goods/list?...`。中间那层是没有 id 的商品详情页，从深链
按返回会先落到「商品信息缺失」的错误态；同时首页也会被顺带建起来发一遍请求。

改成自己拼初始路由栈：根路径只压首页，其它深链压成「首页 + 目标页」，返回键
回到首页而不是错误页。

- 新增 `buildInitialRoutes`，接到 `MaterialApp.onGenerateInitialRoutes`
- 补 3 个用例（根路径单层 / 深链两层且不含 `/goods` / 未知路径先落首页）
- 用例总数 134，覆盖率 1903 / 2309 = 82.4%
- README 的路由小节说明初始栈规则
